# health_monitor_app
This Django project is to create a health monitoring app which can be used to analyse own personal health data and get suggested life style changes and diet plans
##Clone this repo

## Create a virtual env dj
python3 -m venv dj

## Activate venv
source dj/bin/activate

## Install requirements.txt packages
pip install -r requirements.txt

## Run django app
python3 manage.py runserver
